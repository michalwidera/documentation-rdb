# Regenerating xretractor plans

Run `./regen/pic_and_qry.sh` from the documentation repository root. The script uses
`../retractordb/build/Debug/src/retractor/xretractor`; to select another current
executable, set `XRETRACTOR=/path/to/xretractor`.

Each `.rql` file is the source for at least one figure or code listing in the book.
The script writes listings to `regen/out/`, which mdBook inserts into the marked code
blocks using `{{#include ...}}`. DOT figures are written directly to `assets/`.
Every SVG generated by the script has a transparent background (`xretractor -p`).

| Sources | Output in the documentation |
| --- | --- |
| `plan-basic.rql`, `runtime-plan.rql` | Figs. 27 and 29, plus the Fig. 27 listing |
| `dag-1.rql` - `dag-4.rql` | Figs. 33-36 |
| `alias.rql`, `compile-flow.rql`, `debug.rql` | Listings in the aliasing and compilation chapters |
| `wildcard.rql`, `underscore.rql` | Listings for expansion of `*` and `[_]` |
| `substrate-hash*.rql`, `substrate-shift.rql` | Listings in the substrates chapter |
| `dedup.rql`, `absorb-auto.rql`, `absorb-named.rql` | Figs. 37-40 |
| `filter.rql` | Fig. 57 |
| `sum-sequence.rql` | Listing for the summation sequence diagram |

`dedup.rql` feeds two figures: `dedup_po.svg` from the default compiler and
`dedup_przed.svg` from a binary built with `RDB_OPT_DEDUP_SUBSTRATES=OFF`.
The script detects a local ablation build or requires it to be provided through
`XRETRACTOR_NO_DEDUP=/path/to/xretractor`.
